AJAX dan jQuery — Penjelasan & Contoh

🔄 AJAX

AJAX (Asynchronous JavaScript And XML) adalah teknik untuk mengirim dan menerima data dari server secara asinkron di latar belakang — tanpa perlu me-reload halaman. Data yang dikirim bisa berformat XML, JSON, HTML, atau teks biasa.

⚡ jQuery

jQuery adalah library JavaScript yang menyederhanakan manipulasi DOM, penanganan event, animasi, dan permintaan AJAX. Digunakan dengan menyertakan file CDN-nya lalu memanggil fungsi via $() atau jQuery().

/* Contoh jQuery — ubah teks & warna tombol saat diklik */
$("#contohBtn").on("click", function() {
  $("#contohOutput").text("Halo dari jQuery! 🎉").css("color", "#e94560");
  $(this).text("Sudah diklik!").addClass("btn-danger");
});
