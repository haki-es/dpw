Apa itu Bootstrap?

Bootstrap adalah framework CSS open-source yang paling populer di dunia. Dibuat oleh Mark Otto dan Jacob Thornton di Twitter pada tahun 2011, Bootstrap menyediakan komponen UI yang siap pakai dan responsif.

Bootstrap menggunakan sistem grid berbasis 12 kolom dan breakpoint untuk menentukan tampilan di berbagai ukuran layar (xs, sm, md, lg, xl, xxl).

Cara Menambahkan Bootstrap

1. Via CDN (termudah):

<link href="https://cdn.jsdelivr.net/npm/
bootstrap@5.3.2/dist/css/bootstrap.min.css"
rel="stylesheet">

<script src="https://cdn.jsdelivr.net/npm/
bootstrap@5.3.2/dist/js/bootstrap.bundle.min.js">
</script>

2. Via npm:

npm install bootstrap

Sejarah Bootstrap

2011 — Bootstrap 1.0

Dirilis oleh Mark Otto & Jacob Thornton dari Twitter sebagai alat internal.

2013 — Bootstrap 3.0

Perkenalan pendekatan mobile-first. Menjadi framework paling populer di GitHub.

2018 — Bootstrap 4.0

Beralih ke Flexbox, memperkenalkan utilitas spacing dan warna yang lebih lengkap.

2021 — Bootstrap 5.0

Menghapus ketergantungan jQuery, menambahkan CSS Custom Properties, dan menyempurnakan utilitas.

2023 — Bootstrap 5.3

Dukungan penuh Color Mode (dark/light), peningkatan komponen, dan banyak utility baru.
