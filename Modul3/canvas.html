Canvas HTML5

Kesimpulan:
Elemen canvas HTML menyediakan area gambar dengan piksel yang dapat diubah menggunakan JavaScript, beda dengan SVG yang berbasis vektor, canvas menggunakan JavaScript untuk menggambar bentuk, teks, gambar, dan animasi. kode JavaScript dipisahkan ke file js/main.js dan diupload dengan tag script src=js/main.js di bagian akhir badan. fengan eksplorasi ini, dapat menggambar berbagai bentuk seperti persegi, lingkaran, garis, teks, dan gradien menggunakan Canvas.
